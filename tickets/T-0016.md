## Anlass

Brief pm/N-0010: „falls updates gibt, sollen die Server selbstständig neu starten."
Bisher zeigte das Versions-Banner nur an, dass neuer Code auf der Platte liegt (SWR-047),
und der Mensch musste ⟳ drücken (SWR-061).

## Impact-Analyse

Der Neustart-Weg existiert bereits (Exit-Code 42, Schleife in den Startskripten). Neu ist
nur der Auslöser. Risiken und ihre Gegenmittel:

| Risiko | Gegenmittel |
|---|---|
| Handgestarteter Server beendet sich und ist einfach weg | Selbst-Neustart nur mit Marker `MC_NEUSTART_SCHLEIFE=1`, den ausschließlich die Startskripte setzen — ohne Schleife passiert nie etwas |
| Neustart mitten in einer Anfrage (Entscheidung, Digest-Lauf) | Zähler laufender Anfragen; die Wache startet nur bei Ruhe neu, sonst im nächsten Takt |
| Sprint schreibt viele Commits → Neustart-Flattern | Entprellen: derselbe neue Stand muss zwei Durchläufe hintereinander stehen (20 s Takt) |
| Seite im Browser zeigt danach Altdaten | Frontend prüft alle 30 s `/api/version`; neuer `gestartet`-Zeitstempel → automatischer Reload |

Klasse B (kein Budget, keine Außenwirkung) — PM-Beschluss B013, Umsetzung in derselben
Routine-Session wie die Qualifizierung.

## Umsetzung (SWR-073)

- `platform/backend/server.py`: `selbst_neustart_noetig()` (reine, testbare Entscheidung),
  `_neustart_wache()` als Daemon-Thread (Austritt/Stand/Ruhe injizierbar), Zähler in
  `handle_one_request`, Start nur bei gesetztem Marker.
- `mission-control.cmd` / `mission-control-lan.cmd`: setzen `MC_NEUSTART_SCHLEIFE=1`.
- `platform/backend/static/app.js`: Versions-Prüfung alle 30 s, Reload bei neuem
  Startzeitpunkt, Banner nur einmal einfügen.

## Verifikation

`test_backend.py::SelbstNeustartTest` (3 Tests: Entscheidungsmatrix inkl. fehlendem Marker,
laufender Anfrage und Entprellen; Austritt mit Code 42; ohne Marker nie) — 181 Tests grün,
Matrix 73/0, `node --check app.js` grün.
Stichprobe des Auftraggebers: Mission Control über `mission-control.cmd` starten, eine
Session Code ändern lassen — der Server kommt binnen ~40 s von allein neu hoch, die Seite
lädt sich selbst nach.
