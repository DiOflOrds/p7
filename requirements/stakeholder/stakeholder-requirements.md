# Stakeholder Requirements — P7 „Teams im HMI"

| ID | Requirement | Source | Status |
|---|---|---|---|
| STK-017 | As the client I want teams to be visible and operable inside Mission Control: I can read their digests (also on my phone), see how a team is set up (charter, roles, SLA, configuration), change the team's key parameters (period daily/weekly/monthly, report sections, mail delivery) directly in the HMI protected by the PIN, and optionally receive digests by mail — while sensitive team content is never pushed to GitHub and is not readable from the LAN without the PIN. | pm/T-0005 (P7b) | reviewed |
